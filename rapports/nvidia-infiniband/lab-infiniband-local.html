Lab InfiniBand local

Un parcours en quatre niveaux pour apprendre à installer et exploiter une fabric InfiniBand NVIDIA, du simulateur gratuit à la petite fabric commutée. Objectif : maîtriser le Subnet Manager, les outils de diagnostic et la recette, et préparer la certification NCP-AIN. Le niveau 0 a été réellement exécuté pour ce guide : les sorties montrées sont celles du test, et le kit est fourni.

Le parcours

Niveau 0 · 0 €

Simulateur

ibsim + OpenSM + infiniband-diags sur un PC Linux. Découverte, routage, élection, bascule, partitions, pannes de liens. Puis Slurm par-dessus (niveau 0+). Soft-RoCE pour les verbes RDMA, NVIDIA Air pour la partie Ethernet de l'examen.

Niveau 1 · ≈ 130–1 800 €

Deux serveurs dos à dos

Deux cartes ConnectX et un câble. Vrai matériel : DOCA-OFED, firmware, mlxconfig, OpenSM, perftest, mlxlink.

Niveau 2 · ≈ 560–3 100 €

Petite fabric commutée

Un à trois commutateurs EDR d'occasion, quatre nœuds. SM embarqué MLNX-OS, fat-tree, moteurs de routage, HA, ibdiagnet, UFM en évaluation.

Niveau 3

NDR proche production

QM9700, ConnectX-7, UFM. Trop bruyant et trop cher pour un lab personnel : à pratiquer chez un partenaire, un intégrateur ou un client.

Niveau 0 : une vraie fabric simulée, testée

ibsim (projet linux-rdma) simule une fabric InfiniBand au niveau des paquets de gestion. Les vrais binaires opensm, ibnetdiscover, sminfo, smpquery, saquery tournent dessus sans modification, grâce à une bibliothèque chargée en LD_PRELOAD. Il n'y a pas de transport de données : pas de RDMA ni de mesure de débit. Pour tout ce qui concerne le Subnet Manager, c'est en revanche fidèle.

Résultats du test (Ubuntu 24.04, OpenSM 3.3.23, infiniband-diags 50.0, ibsim 0.10)

Installer et lancer

# Ubuntu 24.04 / Debian
sudo apt install opensm infiniband-diags ibsim-utils

# 1. le simulateur charge la topologie
ibsim -s -n fabric.net &

# 2. OpenSM "branché" sur le nœud sm-a
SIM_HOST=sm-a ibsim-run opensm -F opensm-a.conf \
    -f $PWD/sm-a.log &

# 3. les outils, vus depuis gpu1
SIM_HOST=gpu1 ibsim-run sminfo
SIM_HOST=gpu1 ibsim-run ibnetdiscover
SIM_HOST=gpu1 ibsim-run iblinkinfo
SIM_HOST=gpu1 ibsim-run ibroute 4

ibsim renumérote les GUID au chargement (0x1000xx pour les cartes) : les GUID de partitions.conf sont ceux relevés par ibnetdiscover.

Pièges rencontrés pendant le test

1. Sans l'annotation de vitesse (lid 0 4xHDR) en fin de ligne, ibsim affiche « cannot parse remote lid and connection type ». 2. La vitesse simulée n'est pas réaliste (iblinkinfo affiche 53 Gb/s pour un lien déclaré HDR) : ne pas s'en servir pour mesurer. 3. pkill -f opensm lancé depuis un script dont la ligne de commande contient « opensm » tue le script lui-même : préférer pkill -x opensm.

gratuit

Soft-RoCE

modprobe rdma_rxe puis rdma link add rxe0 type rxe netdev eth0 : verbes RDMA, ib_write_bw, MPI/UCX sur une carte Ethernet. C'est du RoCE, pas de l'InfiniBand : ni SM, ni LID.

gratuit

NVIDIA Air

Jumeau numérique cloud pour Spectrum-X, Cumulus, NVUE, NetQ : couvre les 30 % Ethernet de NCP-AIN. Aucune simulation InfiniBand ou UFM trouvée.

30 à 60 jours

UFM en évaluation

UFM génère seul une licence de 30 jours au premier démarrage ; une licence de test de 60 jours peut être demandée. À caler sur la période de révision, avec une fabric réelle (niveau 2).

Niveau 0+ : Slurm par-dessus la fabric simulée

Slurm est l'ordonnanceur qui répartit les jobs sur les nœuds GPU ; il ne gère pas le réseau mais s'appuie dessus. Dans le lab, il se branche sur la fabric ibsim : sa topologie est générée depuis ibnetdiscover et un prolog vérifie le port InfiniBand de chaque nœud avant chaque job. Testé sur la même machine, avec Slurm 26.05.4 (compilé) et 23.11.4 (paquet Ubuntu) : 4 nœuds GPU virtuels (plusieurs slurmd), comptabilité MariaDB, deux clients avec quotas GPU. Détails dans la documentation « Slurm pour clusters GPU souverains ».

firmware

MLNX-OS récent réservé aux contrats de support (portail NVIDIA Enterprise Support ou constructeur OEM). Les images trouvées sur Internet ne sont pas officielles. Le firmware des commutateurs non managés est en revanche public et se met à jour à travers la fabric : flint -d lid-<LID> q puis burn.

bruit

70 à 78 dB(A) à plein régime : incompatible avec un logement. Pièce technique, garage ou baie insonorisée, et allumage uniquement pendant les sessions. Les modifications de ventilateurs risquent alarmes et surchauffe de l'ASIC.

électricité

Deux alimentations par commutateur : deux prises, idéalement deux circuits. Un niveau 2 tient sur un circuit 16 A ; un QM9700 (jusqu'à 1 720 W) demande une ligne dédiée validée par un électricien.

achat

Sources UE et Royaume-Uni : eBay.de, ETB-Tech (garantie 3 ans), bargainhardware.co.uk, servero.co.uk, haehnlein-it.com. Depuis le Royaume-Uni ou les États-Unis : TVA de 20 % à l'import, plus le transport.
